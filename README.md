
# 🚀 Zotero Picker (v1.0)

> **Zotero Picker** 是一款集成于浏览器的学术资源管理外挂。通过浏览器插件与本地后台服务（`zotero_service.exe`）的完美配合，实现网页端文献的极速识别、查重与 Zotero 库的无缝联动。

## ✨ 核心亮点

- 🔍 **智能识别与高亮**：自动精准捕捉网页中的 **DOI** 与 **ISBN** 标识符。完美适配 PubMed、Elsevier等主流学术网站。
- 🚥 **实时查重预警**：网页端直接显示该文献在本地 Zotero 库中的存留状态，避免重复收集。
- ⚡ **极速一键导入**：对于库中缺失的文献，点击网页上的标记即可一键抓取元数据并写入本地 Zotero。
- 🚀 **快捷穿梭定位**：支持从网页端一键唤醒 Zotero，并精准高亮定位到对应文献条目。
- 📡 **服务状态感知**：插件图标实时反馈本地 Flask 接口与 Zotero 数据库的连接健康度。

## 📦 快速开始 (新手必看)

本项目由**「本地后台服务」**和**「浏览器插件」**两部分组成，请按照以下步骤依次配置：

### 第一步：启动本地后台服务 (⚠️ 此处需要您的配置)

1. 双击运行解压后的 `zotero_service.exe`。
2. **【首次运行提示】**：程序会弹出一个路径选择窗口，要求您定位本地的 Zotero 数据库。
   > 💡 **您需要修改/确认的地方**：
   > 请点击 **“选择新路径”** 按钮，找到您电脑上的 `zotero.sqlite` 文件（通常位于 `C:\Users\您的用户名\Zotero\zotero.sqlite`）。
3. 选定后，服务将在后台静默运行并监听本地端口。

### 第二步：安装浏览器插件 (支持 Chrome 与 Edge)

本插件完美兼容 Google Chrome 与 Microsoft Edge 浏览器。请根据您的浏览器选择安装方式：

**🔵 对于 Chrome 浏览器用户：**
1. 在地址栏输入 `chrome://extensions/` 进入扩展程序页面。
2. 开启页面右上角的 **“开发者模式”**。
3. 点击左上角的 **“加载已解压的扩展程序”**。
4. 选择本压缩包中的插件源码文件夹(`Browser_Extension`)，即可。

**🟢 对于 Edge 浏览器用户：**
1. 在地址栏输入 `edge://extensions/` 进入扩展页面。
2. 在页面左下角开启 **“开发人员模式”**。
3. 点击右上角的 **“加载解压缩的扩展”**。
4. 选择本压缩包中的插件源码文件夹(`Browser_Extension`)，即可。

**🎉 安装完成！** 现在随便打开一篇 PubMed 文献网页，体验极速抓取吧！

## ⚙️ 后端逻辑与高级配置说明

本地服务主要依靠同目录下的 `zotero_config.json` 文件来记忆您的数据库路径。您无需手动编辑该文件。

- **5 秒免打扰机制**：如果您之前已经成功配置过路径，下次运行 `zotero_service.exe` 时，弹窗会倒计时 5 秒。若您不进行任何操作，程序将自动读取上次的路径并启动。
- **如何更换数据库路径？** 如果您重装了 Zotero 或移动了数据库位置，只需**删除**服务目录下的 `zotero_config.json` 文件。再次运行 `.exe` 时，程序会重新弹出路径选择窗口供您修改。
